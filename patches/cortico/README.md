## 重新导出补丁

每个补丁只包含自己相对前序补丁的增量。重新导出时，在 `scratch/` 的隔离副本中应用前序补丁，
将前序状态按明确路径暂存，再修改目标补丁的内容。新文件先用 `git add -N -- <路径>` 纳入 diff；
使用 `git diff --binary --output=<补丁绝对路径>` 导出未暂存的增量。
不要把含全部补丁的 `vendor/cortico` diff 写回 `0001`，否则后序补丁会重复应用。
