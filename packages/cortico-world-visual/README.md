# 图像资料 (`world.ts`, `server/`)

她记得的人和东西长什么样：她自己的自设图，别人的设定、宠物、房间……存在她的记忆里，画图时当参考图用。生图本身在 `cortico-world-images`：她挑好图，把记忆句柄交给生图工具，生图工具再按条目 id 向本 World 取外貌说明。

## 存在哪

默认在部署记忆的 `visual/` 下（`<部署>/memory/visual/`），随记忆的 git 一起提交和回滚。一个条目一个文件夹，文件夹名就是 id，`self` 是她自己：

```
memory/visual/
  self/
    entry.md
    正面.png
  团子/
    entry.md
    3f2a9c0b1d4e.png
```

`entry.md` 的头部写名字、别名、主人和来源，正文是给生图模型看的设定：

```markdown
---
name: 团子
aliases: [你家的猫, 那只橘猫]
owner: 361270936
source: private
---
橘色短毛猫，圆脸，左耳有个缺口。
```

`owner` 是 QQ 号，和 `people/<QQ号>.md` 对应；`source` 是 `private` 或 `group:<群号>`，可空。没有 `entry.md`、只放了图的文件夹也算条目，名字取 id。目录固定在记忆里，图片才能用记忆句柄 `mem:visual/<id>/<文件名>` 读取。

## 三种加资料的方式

- 直接往目录里放文件。
- 管理页「图像资料」：新增条目、上传图片、编辑说明。保存带 revision 校验；删掉的条目和图片从目录里删除，记忆的 git 历史里还能找回。
- 她自己用 `visual_save(image, id, name?, aliases?, description?)` 存别人发来的图。

## 存图白名单

`visual_save` 只收 `log:` 句柄，并在事件库里找这张图是谁、在哪发来的：只认 QQ 消息和图片附件（`qq.message`、`qq.image`）和控制台消息（`console.message`），她自己发的图、工具回执、别的 World 的事件都不算。发送者要在设置页「人格 → 全局变量」的白名单 QQ 里，或在本插件的「额外的存图白名单」（QQ 号，逗号分隔）里，两处都每次现读；控制台发的图由「控制台发的图也能存」决定（默认可以）。句柄按内容寻址，同一张图有多人发过时，只要其中有白名单里的人就能存。

存下的条目：主人在条目还没有主人时记成发送者；来源记成那条消息所在的聊天，一旦有私聊来的图，整条就算「私聊所得」。给了的名字、别名、说明覆盖原值，没给的保留。白名单外的人发的图拒绝存，回执说明是谁发的，让她如实告诉对方。

## 她怎么用

条目列表经环境提示词变量 `visual.list` 进入前缀，每行「id：名字（别名）· 主人 · 来源 · 图片文件名」。有人想看时，她用发送工具发记忆句柄 `mem:visual/<id>/<文件名>`；提示词点明「自设」「本地存的图」指的是这里而不是表情包。列表只在前缀重建时读取，新条目要重载前缀她才看到；生图调用每次现读，图片和说明立即生效。画到资料里的对象时，她自己挑符合要求的图（比如只要默认形象就只挑那一张），把 `mem:visual/<id>/<文件名>` 放进 `images_generate` 的 `images`，生图工具按句柄里的 id 附上条目的外貌说明。提示词里出现名字不会自动附图。

「私聊所得」只靠提示词约束她别在群里用：工具调用拿不到当前是哪个聊天，代码这一层没有拦截。

## 给别的 World 用

启动时按部署目录登记到 `globalThis[Symbol.for('mybot.visual-library')]`，停止时注销。`lookupVisual(botDir)` 返回 `{ describe(id) }`，给出条目的名字和外貌说明；图片本身由宿主按记忆句柄读取。本 World 没启用时返回 null，生图照样能用这些图，只是不带说明。生图 World 不 import 本包，只认同一个 Symbol。

每个条目最多 8 张图，单图最多 6 MB，只收 PNG/JPEG/WebP。
