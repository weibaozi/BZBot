# Changelog

## 0.1.1

- 存图白名单也认设置页「人格 → 全局变量」的白名单 QQ；本插件的那一栏改为额外名单。
- 生图改为她自己挑图：把 `mem:visual/<id>/<文件名>` 放进 `images_generate` 的 `images`，不再按条目整包附图；登记给生图 World 的接口只剩 `describe(id)`（名字和外貌说明）。
- 去掉「资料目录」设置：资料固定在记忆的 `visual/` 下，记忆句柄才读得到。
- 条目列表带上图片文件名；环境提示词说明「自设」「本地存的图」指图像资料、不是表情包，想看时用 `mem:visual/<id>/<文件名>` 发送。
- 管理页上传保留原文件名（去掉路径和非法字符，扩展名按实际格式改正，同名不同图加 -2），图片下方显示文件名；同样内容的图复用已有文件。`visual_save` 存的图同样去重，文件名用内容哈希。

## 0.1.0

- 从生图扩展里拆出图像资料：记忆里的 `visual/<id>/`（`entry.md` 加图片），管理页、环境提示词里的条目列表，按部署登记给生图 World 取用。
- 新增 `visual_save`：从事件库确认图片的发送者和聊天，白名单里的人发的图才能存。
