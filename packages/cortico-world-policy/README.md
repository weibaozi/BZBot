# cortico-world-policy — `PolicyWorld` / `PolicyStore`

在管理页编辑多层底层规则。启用且非空的层按界面顺序合并，位于 ORIENTATION 之后、宪法之前，记忆和其他 World 环境提示词保持原顺序。标题只用于管理，正文原样拼接，层间加两个换行，不解释模板占位符。

## 安装和使用

依赖 myBot 的 `0017-world-leading-system-segments.patch`，不能直接在原版 Cortico 中使用。先应用补丁、构建本包，再通过扩展页安装本地目录并启用 `policy` World。未安装补丁时不要启用本包。

进入「底层规则 → 规则分层」，新增、编辑、启停、上下移动或删除各层；左栏修改、右栏实时预览实际合并文本，窄屏上下排列。初始为空，不预置你的规则。保存有二次确认和修订冲突检查。内容存于 `<部署>/policy/layers.json`，备份部署时包含此目录。

保存不修改当前会话的冻结前缀。下次交接、启动或手动重载前缀时读取新版本；立即重载会损失一次缓存。梦境继承触发它的会话快照，包括当时的底层规则。停用插件会使后续前缀不再包含这些规则。

## 权限边界

插件不向模型提供工具，也不把规则存进 Persona 的记忆工作区；聊天和梦境的文件工具无法修改此存储。编辑入口是现有 WebUI 的管理员接口，沿用宿主认证。规则不是秘密，不要放密钥。

这不是操作系统不可变文件：有管理接口或文件系统写权限的人和程序仍可修改。不要给委派任务、MCP 或命令工具授予部署目录的写权限或管理后台凭据。提示词注入防护文本只能指导模型判断，不能取代工具授权和目录权限检查；排列靠前也不保证模型绝对遵守。

损坏或不支持的规则文件会中止前缀组装，不静默忽略。保存前校验最多 64 层、正文合计 200,000 字符。只修改标题不会改变实际前缀正文。

## 验证

运行 `npm test`、`npm run typecheck`、`npm run typecheck:web`。在 bot 停止时执行 `npm run build:web`；运行中的部署验证应使用 `scratch/` 隔离副本。
