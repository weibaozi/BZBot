# Codex 生图 (`world.ts`)

在模型中心添加 Codex OAuth 生图模型，在本扩展中选择它；对应的文本模型在模型中心的生图模型设置里选择。

`images_generate(prompt, images?)` 支持文生图和参考图编辑。要改的图和要参照的图都由她挑好放进 `images`：对话图片传原始 `log:` / `mem:` 句柄，宿主读取字节后通过模型中心交给 Codex。图片失效时明确报错，不猜路径、不抓任意 URL。有图片时使用 `input_image` 和 `image_generation.action=edit`。返回图片句柄，随后由当前渠道工具发送。

## 参考图

图像资料（`cortico-world-visual`）里的图用记忆句柄 `mem:visual/<id>/<文件名>` 传入，只传符合要求的那几张。认出这类句柄时，本扩展按 id 向图像资料取条目的名字和外貌说明，附在提示词后面，并写明每张图是谁的参考图；图像资料没启用时照样能用这些图，只是不带说明。资料怎么存、她怎么知道有哪些图，见那个包的 README。提示词里出现名字不会自动附图。

一次生成最多 8 张图、合计 20 MB。过多时明确报错，需少带几张。默认超时 180 秒，停用或取消会中断调用，不自动重试。

文生图仍兼容普通 `/images/generations` 供应商；图生图优先支持 Codex，其他供应商不支持时明确拒绝，不丢弃参考图。账号实际生图权限以服务端为准。
